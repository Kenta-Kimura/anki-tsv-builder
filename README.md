# Anki TSV Builder

Numbersまたは単語帳OCRの貼り付けから、Ankiに読み込むTSVを作るローカルWebアプリです。英単語学習カード向けに、Oxford Learner's Dictionariesの定義取得、Geminiによる発音記号・CEFR・原義補完、既存Ankiノートとの重複チェックをまとめて行います。

## 起動

通常のNode.jsが使える場合:

```bash
node server.js
```

Codex内蔵Nodeを使う場合:

```bash
/Applications/Codex.app/Contents/Resources/node server.js
```

起動後、ブラウザで開きます。

```text
http://127.0.0.1:5173
```

コードを変更したあとに `server.js` の変更を反映するには、ターミナルで `Ctrl + C` を押してサーバーを止め、同じ起動コマンドを再実行してください。

## 入力形式

画面の「入力形式」ラジオボタンで、Numbers貼り付けまたはOCR貼り付けを選びます。貼り付けるだけで自動読み込みします。

### Numbers

Numbersから以下の6列をコピーして貼り付けます。

```tsv
覚えたい単語	空欄つきの文	日本語訳	パス単備考	でる度	品詞
```

### OCR

単語帳OCR結果から以下の4列を貼り付けます。

```tsv
覚えたい単語	空欄つきの文	日本語訳	パス単備考
```

OCR形式では、画面の「OCR用 でる度」を全行に適用します。品詞は「OCR品詞ブロック」で行数ごとにまとめて割り当てます。Numbers形式ではOCR用の入力欄は非表示です。

OCR品詞ブロックは、上から順に「行数 品詞」で入力します。

```text
30 動詞
40 名詞
15 形容詞
```

上の例では、貼り付けたOCR行の1〜30行目を動詞、31〜70行目を名詞、71〜85行目を形容詞として扱います。例外がある場合は、処理結果テーブルの「品詞」欄で行ごとに修正できます。

## 出力対象の選択

処理結果テーブルの「出力」チェックがONの行だけがTSV出力対象になります。一括補完もチェックONの行だけをGeminiへ送ります。

「すでに知っていた単語」に改行区切りで単語を入力すると、一致する行の出力チェックが自動でOFFになります。比較時は前後空白、全角/半角スペース、タブ、改行を除去します。

## 出力列

```tsv
覚えたい単語	空欄つきの文	日本語訳	発音記号	単語の定義	タイプ2	備考	タグ
```

- 日本語訳は貼り付け入力の値をそのまま使います。Geminiでは補完・上書きしません。
- 定義はOxford Learner's Dictionariesから取得し、`verb: ...` / `noun: ...` のように英語品詞つきで出力します。
- Oxfordから取得できない場合はGeminiの定義補完を使います。
- 備考列は `原義` と `パス単備考` を改行で結合します。
- TSV内のセル内改行はAnkiで崩れにくいよう `<br>` に変換します。
- タグ列の品詞は、入力された品詞表記をそのまま使います。
- CEFRが空欄または未設定の場合、タグ列に `CEFR::未設定` は出力しません。

## Gemini補完

Gemini APIキーは画面から入力します。キーはサーバーには保存しません。「このブラウザにAPIキーを保存」にチェックした場合だけ、ブラウザの `localStorage` に保存します。

補完対象:

- 発音記号
- CEFR
- 原義
- Oxfordで定義が取れない場合の定義

CEFRは、Oxfordページ上で例文の意味に合う語義に設定されたCEFRを最優先します。その語義にCEFRが無い場合だけ、見出し語側の代表的なCEFRを使います。Oxfordから取れずGeminiでも確実に判断できない場合は空欄にし、タグ列にもCEFRタグを出しません。

補完対象外:

- 日本語訳

一括補完は1回のGemini APIリクエストで実行します。処理中は進捗バーと経過秒数を表示しますが、Gemini APIは途中経過を返さないため、行ごとの完了は応答後にまとめて反映されます。

## Gemini使用量

サーバー側でGemini使用量を `data/usage.json` に記録し、画面にRPM/TPM/RPDの使用率を表示します。APIキーはこのファイルには保存されません。

現在登録している制限値:

| モデル | RPM | TPM | RPD |
| --- | ---: | ---: | ---: |
| `gemini-2.5-flash` | 5 | 250,000 | 20 |
| `gemini-3.1-flash-lite` | 15 | 250,000 | 500 |

上記以外のモデルは、表示用の制限値として `gemini-2.5-flash` の値を使います。

## 既存ノート重複チェック

Ankiから書き出したタブ区切りtxtを読み込むと、実データ行の1列目を既存の覚えたい単語として扱います。

- `#separator:tab` や `#html:false` などのメタ行は無視します。
- 新規入力の覚えたい単語と既存txtの1列目だけを比較します。
- 前後の空白、全角/半角スペース、タブ、改行は除去して比較します。
- デフォルトは大文字小文字を区別しません。
- 「大文字小文字を区別する」でcase-sensitiveに切り替えられます。
- 重複があってもTSV出力と一括補完は続行できます。
- 読み込んだ既存単語リストはブラウザの `localStorage` に保存され、次回以降は自動復元されます。
- 保存するのは1列目の単語リストだけで、txt全体は保存しません。

## ローカル保存

ブラウザの `localStorage` に保存するもの:

- Geminiモデル選択
- APIキー保存チェックがONの場合のGemini APIキー
- 既存Ankiノートの1列目単語リスト
- 既存Ankiノートのファイル名メタ情報

サーバー側に保存するもの:

- `data/usage.json`: Gemini使用量履歴

Git管理対象外:

- `.env`
- `data/usage.json`
- `node_modules/`
